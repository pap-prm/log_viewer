# Упрощение интерфейса: только Live режим

## Что изменено

### Убрано
- Режим "Статика" полностью удален
- Двухрежимный переключатель "Статика/Live"
- Условная логика для статического просмотра

### Добавлено
- Кнопка "Стоп/Старт" для управления Live режимом
- Выпадающий список выбора интервала обновления (1, 5, 10, 15, 20, 30, 60 сек)
- Свойство `isPaused` для компонента LiveLogViewer
- Кнопка "Отключить/Подключить" для управления WebSocket соединением

## Новый интерфейс

### Верхняя панель управления

```
[Стоп/Старт] [Интервал ▼] [Отключить/Подключить] [Автопрокрутка] [Очистить] [Скачать]
```

#### Кнопка "Стоп/Старт"
- **Стоп** (красная) - приостанавливает отображение новых строк
- **Старт** (зеленая) - возобновляет отображение
- Новые строки продолжают поступать через WebSocket, но не отображаются

#### Выпадающий список интервалов
- **Мгновенно** - обновление в реальном времени (1 сек)
- **5 сек** - обновление каждые 5 секунд
- **10 сек** - обновление каждые 10 секунд
- **15 сек** - обновление каждые 15 секунд
- **20 сек** - обновление каждые 20 секунд
- **30 сек** - обновление каждые 30 секунд
- **60 сек** - обновление каждые 60 секунд

#### Кнопка "Отключить/Подключить"
- **Отключить** (красная) - закрывает WebSocket соединение
- **Подключить** (зеленая) - восстанавливает WebSocket соединение
- Индикатор подключения показывает текущее состояние

## Использование

### Сценарий 1: Мониторинг в реальном времени
1. Выберите файл в левой панели
2. Убедитесь, что режим "Мгновенно" выбран
3. Наблюдайте за логами в реальном времени
4. Используйте "Стоп" для паузы, "Старт" для продолжения

### Сценарий 2: Мониторинг с низким трафиком
1. Выберите файл
2. Установите интервал "30 сек" или "60 сек"
3. Логи будут обновляться реже, снижая нагрузку

### Сценарий 3: Анализ конкретного события
1. Выберите файл
2. Дождитесь интересующего события
3. Нажмите "Стоп" для паузы
4. Изучите логи без изменений
5. Нажмите "Старт" для продолжения мониторинга

### Сценарий 4: Временное отключение
1. Нажмите "Отключить" для закрытия WebSocket
2. Выполните необходимые действия
3. Нажмите "Подключить" для восстановления соединения

## Технические детали

### Состояния компонента

```typescript
interface App {
  liveInterval: 1 | 5 | 10 | 15 | 20 | 30 | 60;  // Интервал обновления
  isLivePaused: boolean;                            // Пауза Live режима
}

interface LiveLogViewerProps {
  fileName?: string;
  maxLines?: number;
  updateInterval?: number;  // Интервал из App
  isPaused?: boolean;       // Пауза из App
}
```

### Логика работы

1. **WebSocket соединение** всегда активно (если не отключено вручную)
2. **Буферизация** новых строк происходит постоянно
3. **Отображение** зависит от:
   - `isPaused` - если true, строки не добавляются в UI
   - `updateInterval` - определяет частоту добавления из буфера

### Буферизация

```typescript
// Если интервал > 1 сек или режим на паузе
if (updateInterval > 1 || isPaused) {
  bufferRef.current = [...bufferRef.current, ...newEntries];
} else {
  // Мгновенное отображение
  setEntries(prev => [...prev, ...newEntries]);
}
```
