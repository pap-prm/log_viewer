# Обновление ReadLog: Выпадающий список режимов и управление папками

## Что добавлено

### 1. Выпадающий список режимов просмотра

Вместо кнопок "Статика/Live" теперь используется выпадающий список с вариантами:
- **Статика** — просмотр существующих логов
- **Live (мгновенно)** — отслеживание в реальном времени
- **Live (5 сек)** — обновление каждые 5 секунд
- **Live (10 сек)** — обновление каждые 10 секунд
- **Live (15 сек)** — обновление каждые 15 секунд
- **Live (20 сек)** — обновление каждые 20 секунд
- **Live (30 сек)** — обновление каждые 30 секунд
- **Live (60 сек)** — обновление каждые 60 секунд

### 2. Управление несколькими папками с логами

Добавлена возможность:
- Добавлять несколько папок с логами
- Переключаться между папками в левой панели
- Удалять папки (кроме последней)
- Каждая папка имеет свой список файлов

## Инструкция по обновлению

### Шаг 1: Скопируйте новые файлы на сервер

**На машине разработки:**

```bash
# Копируем собранные файлы фронтенда
scp -r dist/* jenkins@omega-test-02:/var/www/html/readlog/
```

### Шаг 2: Очистите кэш браузера

В браузере нажмите **Ctrl + Shift + R** для принудительной перезагрузки без кэша.

### Шаг 3: Проверьте работу

1. Откройте `http://omega-test-02.pmz.motor.loc:5555/`
2. В верхней панели найдите выпадающий список режимов
3. В левой панели найдите секцию "Папки с логами"
4. Нажмите кнопку "+" для добавления новой папки

## Использование

### Выпадающий список режимов

1. Нажмите на выпадающий список в верхней панели
2. Выберите нужный режим:
   - **Статика** — для анализа существующих логов
   - **Live (мгновенно)** — для мониторинга в реальном времени
   - **Live (N сек)** — для обновления с заданным интервалом

### Управление папками

#### Добавление папки

1. В левой панели нажмите кнопку "+" в секции "Папки с логами"
2. Введите название папки (например, "Логи приложения")
3. Введите путь к папке (например, `/var/log/app/`)
4. Нажмите "Добавить"

#### Переключение между папками

1. В левой панели нажмите на нужную папку
2. Список файлов обновится
3. Выберите файл для просмотра

#### Удаление папки

1. В левой панели наведите курсор на папку
2. Нажмите кнопку "×" справа от названия
3. Подтвердите удаление

**Примечание:** Нельзя удалить последнюю папку.

## Структура данных

### Интерфейс папки

```typescript
interface LogFolder {
  id: string;        // Уникальный идентификатор
  name: string;      // Название папки
  path: string;      // Путь к папке
  files: LogFile[];  // Список файлов в папке
}
```

### Состояние приложения

```typescript
const [folders, setFolders] = useState<LogFolder[]>([...]);
const [selectedFolderId, setSelectedFolderId] = useState<string>('default');
const [files, setFiles] = useState<LogFile[]>([]);
const [selectedFile, setSelectedFile] = useState<string | null>(null);
```

## API для сервера

Для поддержки нескольких папок необходимо обновить API сервера:

### GET /api/folders

Возвращает список настроенных папок:

```json
{
  "success": true,
  "folders": [
    {
      "id": "default",
      "name": "Логи приложения",
      "path": "/opt/assembly_visual/logs/"
    },
    {
      "id": "custom",
      "name": "Дополнительные логи",
      "path": "/var/log/app/"
    }
  ]
}
```

### GET /api/folders/:folderId/files

Возвращает список файлов для конкретной папки:

```json
{
  "success": true,
  "folderId": "default",
  "files": [
    {
      "name": "app.log",
      "size": 1234567,
      "lastModified": "2026-11-02T10:00:00.000Z"
    }
  ]
}
```

## Примеры использования

### Пример 1: Мониторинг нескольких приложений

```
Папка 1: "Основное приложение" → /opt/app1/logs/
Папка 2: "Фоновый сервис" → /opt/app2/logs/
Папка 3: "API сервер" → /opt/api/logs/
```

Переключайтесь между папками для мониторинга разных приложений.

### Пример 2: Анализ логов с разными интервалами

```
1. Выберите папку "Основное приложение"
2. Установите режим "Live (5 сек)" для мониторинга
3. Переключитесь на папку "Фоновый сервис"
4. Установите режим "Live (30 сек)" для редких событий
```

### Пример 3: Сравнение логов

```
1. Откройте два окна браузера
2. В первом окне выберите папку "До обновления"
3. Во втором окне выберите папку "После обновления"
4. Сравнивайте логи в реальном времени
```

## Производительность

- **Переключение между папками** — мгновенное (данные уже загружены)
- **Добавление новой папки** — требует загрузки списка файлов
- **Удаление папки** — мгновенное
- **Память** — каждая папка хранит свой список файлов

## Ограничения

- **Максимум папок** — не ограничено (но рекомендуется не более 10)
- **Автообновление** — работает только для текущей выбранной папки
- **WebSocket** — подключается только к текущей папке

## Устранение неполадок

### Проблема: Папка не добавляется

**Решение:**
1. Проверьте, что путь к папке существует
2. Проверьте права доступа к папке
3. Проверьте логи сервера

### Проблема: Файлы не загружаются

**Решение:**
1. Проверьте путь к папке
2. Проверьте права доступа
3. Перезапустите сервис readlog

### Проблема: Переключение между папками не работает

**Решение:**
1. Очистите кэш браузера (Ctrl + Shift + R)
2. Проверьте консоль браузера на ошибки
3. Перезагрузите страницу
