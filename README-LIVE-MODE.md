# Добавлена функция Live режима (tail -f)

## Что нового

Добавлена функция **автообновления логов в реальном времени**, аналогичная команде `tail -f` в Linux.

## Возможности

✅ **Отслеживание в реальном времени** — новые строки появляются автоматически  
✅ **WebSocket соединение** — мгновенная доставка изменений  
✅ **Автопрокрутка** — автоматическая прокрутка к новым строкам  
✅ **Подсветка уровней** — ERROR, WARN, FATAL выделяются цветом  
✅ **Управление** — пауза, возобновление, очистка экрана  
✅ **Фильтрация** — можно отслеживать конкретный файл  

## Как использовать

### 1. Переключитесь в Live режим

В верхней панели найдите переключатель:

```
[Статика] [Live]
```

Нажмите **"Live"**.

### 2. Управление

- **Остановить/Запустить** — пауза/возобновление отслеживания
- **Автопрокрутка** — включение/отключение автоматической прокрутки
- **Очистить** — удалить все строки с экрана

### 3. Индикатор подключения

- 🟢 **Зелёная точка** — подключено, новые строки поступают
- 🔴 **Красная точка** — отключено

## Установка на сервере

### Быстрая установка

```bash
# 1. Скопируйте новые файлы на сервер
scp server/websocket.js server/package.json server/server.js jenkins@omega-test-02:/opt/readlog/
scp -r dist/* jenkins@omega-test-02:/var/www/html/readlog/

# 2. На сервере установите зависимости
ssh jenkins@omega-test-02
cd /opt/readlog
sudo npm install ws chokidar --save
sudo chown -R readlog:readlog node_modules

# 3. Перезапустите сервис
sudo systemctl restart readlog

# 4. Проверьте логи
sudo tail -f /var/log/readlog/server.log
```

Должны появиться строки:
```
✓ WebSocket сервер запущен на /ws/logs
✓ Отслеживание файлов запущено: /opt/assembly_visual/logs/
```

### Проверка в браузере

1. Откройте `http://omega-test-02.pmz.motor.loc:3001/`
2. Нажмите **"Live"**
3. Должен появиться индикатор **"Подключено"**
4. Новые строки будут появляться в реальном времени

## Тестирование

```bash
# В другом терминале генерируйте тестовые логи
echo "$(date '+%Y-%m-%d %H:%M:%S') [test] INFO Test message $(date +%s)" >> /opt/assembly_visual/logs/app.log
```

Новая строка должна появиться в браузере в течение 1-2 секунд.

## Возможные проблемы

### WebSocket не подключается

```bash
# Проверьте, что порт открыт
sudo firewall-cmd --list-ports

# Если порт 3001 не открыт, добавьте его
sudo firewall-cmd --permanent --add-port=3001/tcp
sudo firewall-cmd --reload
```

### Ошибка "Cannot find module 'ws'"

```bash
cd /opt/readlog
sudo npm install ws chokidar --save
sudo chown -R readlog:readlog node_modules
sudo systemctl restart readlog
```

### Новые строки не появляются

```bash
# Проверьте права на директорию с логами
sudo chmod 755 /opt/assembly_visual/logs/
sudo chmod 644 /opt/assembly_visual/logs/*.log
```

## Использование

**Live режим** — для мониторинга ошибок в реальном времени, отладки приложений, отслеживания производительности.

**Статический режим** — для анализа исторических данных, поиска конкретных ошибок, экспорта данных для отчётов.

## Поддержка

При возникновении проблем проверьте:
1. Логи сервера: `sudo journalctl -u readlog -n 50`
2. Логи приложения: `sudo tail -f /var/log/readlog/server.log`
3. Права доступа: `ls -la /opt/readlog/`
4. Firewall: `sudo firewall-cmd --list-all`
