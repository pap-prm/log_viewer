# Исправление: Загрузка существующих строк логов

## Проблема

В Live режиме не отображались существующие строки логов при выборе файла. Отображались только новые строки, поступающие через WebSocket.

## Решение

Добавлена загрузка начального содержимого файла при выборе:

1. При выборе файла вызывается API `fetchLogFile(fileName)`
2. Содержимое файла парсится через `parseLogContent()`
3. Существующие строки отображаются в интерфейсе
4. Затем новые строки добавляются через WebSocket

## Изменения в коде

### LiveLogViewer.tsx

1. Добавлен импорт `fetchLogFile` и `parseLogContent`
2. Добавлен `useEffect` для загрузки начального содержимого:

```typescript
useEffect(() => {
  if (!fileName) return;

  // Сбрасываем состояние при смене файла
  setEntries([]);
  lineCounter.current = 1;
  bufferRef.current = [];

  const loadInitialContent = async () => {
    try {
      const fileData = await fetchLogFile(fileName);
      const initialEntries = parseLogContent(fileData.content);
      
      // Устанавливаем начальные записи
      setEntries(initialEntries.slice(-maxLines));
      
      // Обновляем счетчик строк
      lineCounter.current = initialEntries.length + 1;
      
      console.log(`✓ Загружено ${initialEntries.length} строк из файла ${fileName}`);
    } catch (err) {
      console.error('Ошибка загрузки начального содержимого:', err);
    }
  };

  loadInitialContent();
}, [fileName, maxLines]);
```

## Логика работы

### При выборе файла

1. Сбрасываются существующие записи
2. Сбрасывается счетчик строк
3. Очищается буфер
4. Загружается содержимое файла через API
5. Парсится в массив записей
6. Отображаются последние `maxLines` строк (по умолчанию 1000)
7. Обновляется счетчик строк

### При получении новых строк через WebSocket

1. Проверяется, что сообщение для текущего файла
2. Строки парсятся в записи
3. Если интервал = 1 (мгновенно) и не на паузе:
   - Добавляются сразу в `entries`
4. Иначе:
   - Добавляются в буфер
   - Периодически переносятся из буфера в `entries`

3. Должны отобразиться существующие строки
4. В консоли браузера (F12) должно быть:
   ```

   ```
5. Новые строки должны добавляться в реальном времени

## Производительность

- Загрузка файла происходит один раз при выборе
- Для больших файлов (>1000 строк) отображаются только последние 1000 строк
- WebSocket продолжает работать для добавления новых строк
- Буферизация работает как раньше для интервалов > 1 сек
