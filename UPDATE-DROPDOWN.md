# Обновление ReadLog с выпадающим списком интервалов

## Что добавлено

✅ **Выпадающий список выбора интервала обновления** в Live режиме
- Варианты: 1 сек, 5 сек, 10 сек, 15 сек, 30 сек, 60 сек
- По умолчанию: 5 сек
- Расположен в панели управления Live режима

## Инструкция по обновлению

### Шаг 1: Скопируйте новые файлы на сервер

С машины разработки выполните:

```bash
# Копируем собранные файлы фронтенда
scp -r dist/* jenkins@omega-test-02:/var/www/html/readlog/

# Копируем обновлённый server.js (если ещё не скопирован)
scp server/server.js jenkins@omega-test-02:/opt/readlog/
```

### Шаг 2: На сервере установите права и перезапустите

```bash
# Установите права
sudo chown -R readlog:readlog /opt/readlog
sudo chown -R root:apache /var/www/html/readlog

# Перезапустите сервис
sudo systemctl restart readlog

# Проверьте статус
sudo systemctl status readlog
```

### Шаг 3: Очистите кэш браузера

В браузере нажмите **Ctrl + Shift + R** (или **Ctrl + F5**) для принудительной перезагрузки без кэша.

### Шаг 4: Проверьте работу

1. Откройте `http://omega-test-02.pmz.motor.loc:3001/`
2. Переключитесь в режим **Live** (кнопка в верхней панели)
3. В панели управления Live режима должен появиться выпадающий список **"Обновление:"** с вариантами:
   - 1 сек
   - 5 сек (по умолчанию)
   - 10 сек
   - 15 сек
   - 30 сек
   - 60 сек

## Если список не появился

### Проверьте версию файла

На сервере проверьте, что файл обновлён:

```bash
# Проверьте размер файла (должен быть около 194 KB)
ls -lh /var/www/html/readlog/assets/index-*.js
```

### Очистите кэш браузера полностью

1. Откройте DevTools (F12)
2. Перейдите на вкладку **Network**
3. Поставьте галочку **Disable cache**
4. Обновите страницу (Ctrl + Shift + R)

### Проверьте консоль браузера

Откройте DevTools (F12) и перейдите на вкладку **Console**. Если есть ошибки JavaScript, скопируйте их и покажите мне.

## Проверка работы WebSocket

В консоли браузера (F12 → Console) выполните:

```javascript
const ws = new WebSocket('ws://omega-test-02.pmz.motor.loc:3001/ws/logs');
ws.onopen = () => console.log('✓ WebSocket подключён');
ws.onmessage = (e) => console.log('Получено:', JSON.parse(e.data));
ws.onerror = (e) => console.error('Ошибка:', e);
```

Если WebSocket работает, вы увидите сообщение "✓ WebSocket подключён".

## Логи сервера

Проверьте логи на сервере:

```bash
sudo tail -f /var/log/readlog/server.log
```

Должны быть строки:
```
✓ WebSocket сервер запущен на /ws/logs
✓ Отслеживание файлов запущено: /opt/assembly_visual/logs/
```

## Структура панели управления Live режима

```
┌─────────────────────────────────────────────────────────────┐
│ ● Подключено  Файл: app.log                                │
│                                                              │
│ [Остановить] [Автопрокрутка] Обновление: [5 сек ▼] [Очистить] │
└─────────────────────────────────────────────────────────────┘
```

Выпадающий список **"Обновление:"** должен быть между кнопкой "Автопрокрутка" и кнопкой "Очистить".

## Если проблема сохраняется

Пришлите скриншот панели управления Live режима и вывод консоли браузера (F12 → Console).
