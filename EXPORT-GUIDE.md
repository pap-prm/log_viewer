# Функции экспорта и сохранения логов

## Обзор

Log Viewer предоставляет несколько способов сохранения и экспорта лог-данных на ваш компьютер.

---

## Способы экспорта

### 1. Быстрое скачивание файла (верхняя панель)

**Где:** Зелёная кнопка "Скачать" в верхней панели

**Что делает:** Скачивает текущий открытый лог-файл целиком

**Когда использовать:** Когда нужно сохранить оригинальный файл без изменений

```
[Загрузить] [Скачать ↓]  ← зелёная кнопка
```

---

### 2. Скачивание из списка файлов (боковая панель)

**Где:** Иконка стрелки вниз при наведении на файл в списке

**Что делает:** Скачивает выбранный файл из списка

**Когда использовать:** Когда нужно быстро скачать файл, не открывая его

**Как использовать:**
1. Наведите курсор на файл в списке
2. Появится иконка скачивания (стрелка вниз)
3. Кликните по ней

---

### 3. Расширенное меню экспорта (основная панель)

**Где:** Кнопка "Экспорт" в заголовке просмотра лога

**Что содержит:**

#### Скачать файл
- **Весь лог** — полный файл без изменений
- **Отфильтрованные** — только записи, соответствующие текущим фильтрам по уровням
- **Результаты поиска** — только записи, найденные по поисковому запросу

#### Экспорт в CSV
- Формат для открытия в Excel, Google Sheets, LibreOffice Calc
- Колонки: Line Number, Timestamp, Level, Message
- Поддержка кириллицы (UTF-8 с BOM)
- Полезно для анализа и построения графиков

#### Копировать в буфер
- **Все записи** — копирует отфильтрованные записи в буфер обмена
- **Результаты поиска** — копирует только найденные записи
- Удобно для вставки в email, чат, документацию

---

## Примеры использования

### Пример 1: Сохранить только ошибки

1. Откройте лог-файл
2. Нажмите "Только ошибки" (или отключите INFO, DEBUG, TRACE)
3. Нажмите "Экспорт" → "Отфильтрованные"
4. Файл сохранится как `app_filtered_2026-10-23T08-41-00.log`

### Пример 2: Найти и сохранить конкретные ошибки

1. Откройте лог-файл
2. Введите в поиск: `OutOfMemoryError`
3. Нажмите "Экспорт" → "Результаты поиска"
4. Файл сохранится как `app_search_OutOfMemoryError_2026-10-23T08-41-00.log`

### Пример 3: Анализ в Excel

1. Откройте лог-файл
2. Примените нужные фильтры
3. Нажмите "Экспорт" → "Экспорт в CSV"
4. Откройте файл в Excel
5. Стройте графики, фильтруйте, анализируйте

### Пример 4: Отправить ошибки коллеге

1. Откройте лог-файл
2. Отфильтруйте по ERROR
3. Нажмите "Экспорт" → "Копировать в буфер" → "Все записи"
4. Вставьте в email или чат (Ctrl+V)

## Форматы файлов

### .log (текстовый)
- Обычный текстовый файл
- Каждая строка — одна запись лога
- Сохраняет форматирование и stack traces
- Можно открыть в любом текстовом редакторе

### .csv (табличный)
- Разделитель: запятая
- Кодировка: UTF-8 с BOM (для корректной кириллицы в Excel)
- Колонки:
  - Line Number — номер строки
  - Timestamp — временная метка
  - Level — уровень лога (ERROR, WARN, и т.д.)
  - Message — полное сообщение
- Экранирование кавычек по стандарту CSV

## Именование файлов

### Для скачивания оригинала
```
app-2026-10-22.log  ← оригинальное имя
```

### Для отфильтрованных записей
```
app_filtered_2026-10-23T08-41-00.log
```

### Для результатов поиска
```
app_search_OutOfMemoryError_2026-10-23T08-41-00.log
```

### Для CSV
```
app_2026-10-23T08-41-00.csv
```

## Технические детали

### Скачивание файлов
- Используется `Blob` API и `URL.createObjectURL()`
- Автоматическая очистка памяти после скачивания
- Работает во всех современных браузерах

### Копирование в буфер
- Используется `navigator.clipboard.writeText()` (современный API)
- Fallback на `document.execCommand('copy')` для старых браузеров
- Визуальное уведомление "✓ Скопировано"

### CSV экспорт
- Добавляется BOM (Byte Order Mark) для корректного отображения UTF-8 в Excel
- Экранирование кавычек: `"` → `""`
- Все значения оборачиваются в кавычки

---

## Ограничения

- Максимальный размер файла зависит от памяти браузера
- Для очень больших файлов (>100 MB) рекомендуется использовать фильтры
- Копирование в буфер может быть заблокировано политиками безопасности браузера

---

## Советы

💡 **Используйте фильтры перед экспортом** — это уменьшит размер файла и уберёт ненужную информацию

💡 **CSV удобен для анализа** — можно строить графики, искать паттерны, импортировать в базы данных

💡 **Копирование в буфер** — быстрый способ поделиться ошибками с коллегами без скачивания файла

💡 **Результаты поиска** — сохраняйте найденные ошибки для дальнейшего анализа

## API для разработчиков

Если нужно добавить свои функции экспорта, используйте утилиты из `src/utils/download.ts`:

```typescript
import { 
  downloadLogFile,
  downloadFilteredLog,
  downloadSearchResults,
  downloadAsCSV,
  copyToClipboard
} from './utils/download';

// Скачать файл
downloadLogFile(content, 'filename.log');

// Скачать отфильтрованные записи
downloadFilteredLog(lines, 'original.log', 'filter_info');

// Экспорт в CSV
downloadAsCSV(entries, 'filename.log');

// Копировать в буфер
await copyToClipboard(text);
```
